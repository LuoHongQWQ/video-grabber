为什么有些平台需要配置 cookies？

小红书、B站高清、部分抖音内容需要登录态才能拿到原始码流。用浏览器插件导出 Netscape 格式的 cookies.txt，放到项目的 config/cookies.txt，重启服务即可。

为什么要下载到服务器再转给我？

平台对视频直链做了防盗链和签名校验，浏览器直接访问会 403。服务器携带正确的 Referer 拉流后再输出，才能稳定拿到无水印原画。文件仅保存在你本机的 downloads 目录。

画质增强能提升多少？

分辨率提升使用 Lanczos 重采样，边缘更干净，但无法凭空生成细节；帧率提升使用 minterpolate 运动补偿插帧，画面更顺滑，适合动画、运动镜头。两者都会重新编码，原片建议保留。

使用说明

1. 基本流程

粘贴抖音 / B站 / 小红书 / 快手链接 → 解析 → 选择清晰度 → 下载视频、音频或封面。

2. 去水印原理

直接读取平台的原始播放流（非页面上的水印预览版），不做二次压缩，因此没有平台水印、画质也最高。

3. 配置 cookies（可选）

部分内容需要登录态。用浏览器扩展导出 Netscape 格式 cookies，保存为 config/cookies.txt，重启服务后生效。

4. 画质增强

选择目标分辨率与帧率后开始增强，任务在后台运行。插帧与 4K 转码较慢，请耐心等待任务队列完成。

5. 合规提示

请只下载你有权保存的内容，不要用于二次分发或商业用途。
